# Debug Log

## Level __: ______________

**Symptom.** What did I see? Exact error text.

**Reproduce.** Steps that make it happen every time.

**Layer.** Server start / request / server route / response data / client code

**Hypothesis.** What I think is wrong, and why.

**Evidence.** What I checked (tool and what it showed).

**Root cause.** The real reason, in one or two sentences.

**Fix.** File, line, what I changed.

**Verify.** How I proved it works and nothing else broke.

**Lesson.** What I will check first next time.
